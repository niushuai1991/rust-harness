## 关系说明

- 总体计划描述全局架构与阶段目标，多协议专项计划补充模型接入约定；两者共同作为维护依据。
- CLI 命令行调用计划为宿主接口专项计划，实施后桌面端与 JSON-RPC 约定保持不变。
- ACP 协议接口计划为宿主接口专项计划，与 CLI 计划并列，均不改变桌面端约定。
- LSP 语言服务集成计划为模型工具能力专项计划，只读工具免审批，文件改动仍只落隔离副本。
- 内置浏览器集成计划为模型工具能力专项计划，与 LSP 计划并列；工具默认审批，页面内容视为不可信。
- 子代理可视化计划为协作能力专项计划，`SessionInfo.parentId` 为运行时推导字段，存储层不落库。
- P2 后台任务桌面可视化计划为 P2 验收项专项计划，只补齐人机可见性，不改变 orchestration 工具语义与审批策略。
- 计划/目标管理面板计划为 P2「计划/目标」收尾专项，面板为只读派生视图，事件流仍是唯一事实来源，不新增 UI 写入通道。
- 模型设置计划为模型接入专项计划，替代多协议计划中"模型标识手动录入"的单层模型形态；内置目录只读、个人覆盖可写，升级语义与多协议计划一致。
- 输入框斜杠快捷指令计划落地 cli-plan 预留的 REPL 体验升级，仍不做全屏 TUI；两端 `/init` `/plan` `/goal` 提示词以 CLI 常量为单一事实源；2026-11-07 扩展的加号添加菜单只插入斜杠命令，计划/目标仍由模型经工具写入，面板保持只读派生视图。
- PTY 执行世界计划为 P2 验收项专项计划，自研 ConPTY 与受限 token 沙箱配对构成单一本地执行世界；`PtyWorld` trait 为 P3 SSH 远端执行的接入 seam，终端打开一次审批覆盖后续输入。
- 智谱 Coding Plan 额度计划依附模型设置计划的两级结构，属展示层扩展；额度快照即查即返不落库，不改变内置供应商个人覆盖语义。
- 配置预设分层计划为 P2 验收项专项计划，预设为命名的能力配置包（模型/effort/审批策略），解析优先级为显式参数>预设>宿主缺省；目录与模型设置计划同构（内置合成只读、用户自定义可写），预设 approval 仅 CLI/JSON-RPC/ACP 生效，桌面保持交互式审批。
- 当前完成情况以 [能力状态矩阵](capability-matrix.md) 为准，具体执行与验证证据见 [交付记录](delivery.md)。
- 后续发布仅构建使用系统已有 WebView2 的单一 NSIS 包；专项计划中的双安装包与测试数量仅对应 0.1.2 当次交付。

## 维护约定

- 新规范、设计和实施计划只放在 `docs/specs/`，并在本索引登记相对链接、一句话范围及有依据的日期和状态。
- 未标注的信息不推断；实现、验证与未完成状态分别说明，不把接口预留记为功能完成。
- 规范移动、改名或删除时，同步修改本索引及所有引用；明确替代关系后删除旧规范，不留重复副本。
- 交付、进度、验证及审查记录继续放在 `docs/`，注明对应版本或记录时状态。
- 根目录 [AGENTS.md](../AGENTS.md) 保持指向本索引。
