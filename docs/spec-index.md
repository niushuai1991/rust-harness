## 维护约定

- 新规范、设计和实施计划只放在 `docs/specs/`，并在本索引登记相对链接、一句话范围及有依据的日期和状态。
- 未标注的信息不推断；实现、验证与未完成状态分别说明，不把接口预留记为功能完成。
- 规范移动、改名或删除时，同步修改本索引及所有引用；明确替代关系后删除旧规范，不留重复副本。
- 交付、进度、验证及审查记录继续放在 `docs/`，注明对应版本或记录时状态。
- 根目录 [AGENTS.md](../AGENTS.md) 保持指向本索引。
