# 会话回合导航

- 日期：2026-11-19
- 状态：设计及验收规范
- 范围：桌面会话用户消息导航；相关：[回合回复呈现](turn-reply-presentation.md)、[长会话时间线](long-session-timeline.md)。

## 目标与界面

聊天区左缘垂直居中显示用户消息开头；宽度跟随聊天区域在 24–124px 间变化，窄时至少展示一个完整汉字或可容纳的英文字母。导航拥有独立预留空间，不遮挡聊天与输入区。空间不足时隐藏。导航列表独立滚动，鼠标悬停或键盘聚焦时对应文字略微放大，弹出至多 160 个字素的用户消息卡片（超长省略），离开或失焦关闭。支持键盘操作、完整摘要无障碍名称与减少动态效果。

点击导航跳转至对应用户消息，聊天滚动时同步当前项；浏览历史时实时更新不得抢回底部。目录包括历史与实时用户消息，以事件 id 和数值 seq 去重排序；没有正文时显示「用户输入」，不泄露工具、助手或附件正文。目录按页加载，切换会话、重复点击与失败时不能错跳或污染当前会话。

## 数据与限制

目录使用受限分页的用户消息摘要；每页默认 100 条、最多 200 条，附有更早游标。跳转未加载目标时顺序加载历史页面，显示进度并支持取消及重试，不改变事件日志或制造时间线缺口。极长会话中的远距离跳转可能较慢且占用更多内存；本功能不宣称实现时间线虚拟化或有界历史缓存。

## 验收

覆盖分页、空消息、长文本及组合字符、目录与实时事件去重、历史跳转、加载失败重试、竞态取消、滚动同步和自动跟随。验证宽窄窗口、右侧面板、鼠标和键盘悬停卡片，以及输入区和导航不重叠。按仓库要求运行前端和 Rust 检查。
