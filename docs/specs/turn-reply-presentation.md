# 回合回复呈现：过程折叠与轮尾复制

- 日期：2026-11-19（计划拟制）
- 修订：2026-11-19，补充 Shell 命令折叠展示及历史结果回退规则。
- 修订：2026-11-19，Shell 命令由折叠卡片改为无边框内联行与浅底详情面板；新增用户消息气泡呈现。
- 修订：2026-11-19，过程区升级为合并组（运行中统计扫光、完成统计收起）；全局去除消息头像列；复制入口收敛为仅轮尾总结一处（用户消息按钮移除）。
- 状态：现行规范；能力与验证状态见[能力状态矩阵](../capability-matrix.md)
- 范围：桌面端会话时间线的回合呈现形态——一个回合（turn）对用户是一个回复单元：过程收纳进合并组，复制入口只在轮尾总结一处，复制内容为整轮文本合并。纯前端呈现约定，不改后端事件契约。相关：[长会话时间线](long-session-timeline.md)。

## 背景与决策

会话时间线以 `SessionEvent` 平铺存储，`turn.start` / `turn.end` 划定回合边界。模型每次工具调用迭代各落一条 `assistant.message`，其中大量正文为空；空正文消息卡与工具行交替平铺，命令呈现被拆散成一条条独立对话，头像列占用横向空间且信息量低。复制按钮曾逐条挂在用户与助手消息上，口径碎片化。

用户拍板对齐目标形态：**一轮对用户是一个回复**——过程收纳进合并组、头像列全局去除、复制入口只在轮尾总结一处：

1. 运行中回合：用户消息常驻，其余过程事件收进合并组，组头统计带扫光、默认展开、可手动折叠；
2. 完成回合：同一合并组形态，组头变统计文本默认收起，点击展开；
3. 全局去除消息头像与「Rust Harness」标签行：用户消息以气泡为唯一标识，助手消息为无边框正文流；
4. 复制入口全局仅轮尾总结一处（`copyText` = 回合内全部 `assistant.message` 正文合并）；用户消息、中间说明、工具行均无复制按钮；
5. 异常终态回合（`turn.end` 为 error/cancelled）与回合外散事件保持平铺与助手消息逐条按钮的现状（诊断形态，便于分段复制现场），但同样去头像列、用户消息无按钮。

## 呈现形态矩阵

| 回合形态 | 过程区 | 复制按钮 |
|---|---|---|
| 运行中（回合未闭合） | 合并组：组头「正在执行 · N 条命令 · N 次编辑」扫光，默认展开可折叠 | 无 |
| 完成（`turn.end` completed） | 合并组：组头「已执行 · N 条命令 · N 次编辑 · 用时X」默认收起 | 仅轮尾总结，复制整轮合并文本 |
| 异常终态（error / cancelled） | 平铺（诊断形态不变） | 助手消息逐条 |
| 回合外散事件 | 平铺（现状不变） | 助手消息逐条 |
| 用户消息 | — | 无按钮 |

运行中回合的 `turn.end(completed)` durable 事件到达后即从运行中组切为完成组——"运行中展开、结束收起"，无需额外过渡处理。

## 过程合并组

- 组内范围为回合内轮尾总结之前的全部过程事件：中间 `assistant.message` / `assistant.attempt`、`tool.call` / `tool.result`、reasoning、提问卡、子代理卡等；`turn.start`、`turn.end`、`user.message` 不入组（用户消息与轮尾总结常驻）。
- 组头统计口径：`tool.call` 中 `name=shell` 计命令数，`name=write` / `edit` 计编辑数；孤儿结果不计。
- 组头文案：运行中「正在执行 · N 条命令 · N 次编辑」（无统计时「正在执行…」），完成「已执行 · N 条命令 · N 次编辑 · 用时X」（无统计时回退「本轮已完成，用时X」）；时长从 `turn.start` 到 `turn.end` 的 `createdAt` 计算。
- 运行中组默认展开（`open` 随重渲染保持，手动折叠在下次事件到达前有效）；完成组默认收起，手动展开不受渲染干扰。
- 组体为浅底圆角面板带左侧导线，内部沿用时间线渲染（Shell 内联行、文件编辑分组、提问卡等），过程行相对导线缩进；中间说明以小字呈现，左侧带圆点标记。
- 轮尾总结取回合内**最后一条** `assistant.message`（`lastIndexOf` 语义不变）。
- 合并组内的中间助手消息：空正文且无 reasoning 不渲染；仅 reasoning 只渲染思考折叠块；有正文以 `.proc-note` 小字弱化呈现。均不带复制按钮。
- 每条助手消息内的 reasoning 折叠块、Shell 行与工具卡折叠行为均不变。

## 消息形态（无头像列）

- 时间线不再渲染头像与「Rust Harness」标签行；`.message` 为纯文档流块。
- 用户消息：引用块、正文与附件包裹在浅底气泡容器内（浅色底、细边框、右上角圆角收小，宽度自适应上限 560px），气泡是用户发言的唯一视觉标识；无复制按钮。
- 助手消息：无边框正文流；轮尾总结正文下方保留复制按钮（全场唯一）。
- 运行中流式卡：muted 小字标签「正在思考与执行」+ reasoning 折叠块 + 正文与光标；思考指示器保留「正在思考」accessible name（`role="status"`）与动画，仅去除头像标签壳。
- 工具卡、Shell 行等不再为头像列缩进，与正文左缘对齐；合并组体内相对导线缩进。

## Shell 命令展示

- 同一时间线分组内按调用 ID 关联 Shell 调用与结果；匹配唯一且顺序正确时合为一个内联条目，缺失、重复或未匹配时保留独立事件兜底。其他事件和文件修改分组的顺序保持不变。
- 命令条目为一行无边框摘要：终端图标 + 「已执行」+ 单行截断的命令文本。完成态不显示状态词；拒绝、取消、失败、结果未知等异常终态在行内显示红色状态词。条目整体可点击展开与收起，hover 才出现展开箭头，展开后箭头旋转常驻。
- 结果未到达时（回合运行中）状态词为「正在执行」并带文字扫光，不虚构耗时和实时输出；此时展开详情显示等待结果提示。
- 展开后的详情为无边框浅底圆角面板：`$` 前缀加原始命令，限高三行，超出出现「展开命令/收起」文字按钮；输出限高五行滚动，标准错误红色显示；底部小字显示退出码（非零或异常终态为红色）；空输出明确标注；无法解析时原样展示，并保留截断提示和附件下载入口。
- 完成回合的合并组默认收起，展开后命令条目仍默认收起。

## 复制内容合并

- 复制入口全场唯一：轮尾总结左下角复制按钮；
- 合并范围：回合内全部 `assistant.message` 的 `data.content`（经 `printable` 处理），按 `\n\n` 连接；
- 不包含：`reasoning`（思考过程）、工具参数与输出、`assistant.attempt`（失败半截内容）、用户消息正文；
- 回合内仅一条 `assistant.message` 时，合并结果即该条正文，行为与现状一致；
- 回合内没有 `assistant.message`（如纯工具异常回合）时无总结卡，无复制入口。

## 实现要点

- `ProcessGroup`：组头（图标 + 统计文本 + 箭头）+ 组体（浅底面板包 `EventList`）；`running` 控制扫光与默认展开，`durationText` 携带完成时长；`hideCopy` 透传。
- `CompletedTurn` 改用 `ProcessGroup`（`running=false`）；`OpenTurnSection` 承接运行中回合：拆出 user 消息常驻，其余进 `ProcessGroup(running=true, hideCopy)`。
- `EventCard` 可选 props：`copyText?: string` 与 `hideCopy?: boolean`；assistant 分支按 `hideCopy` 区分轮尾正文流与中间 `.proc-note` 小字；user.message 分支无头像、无按钮。
- `durationText` 为纯时长函数（小时/分/秒拼接），组头与「本轮已完成」回退共用。
- `ShellCommandCard` 渲染为受控行（`role="button"` + `aria-expanded` + Enter/Space 键支持）；配对与输出解析逻辑（`shellEvents.ts`）不变。
- 纯前端改动：不新增事件 kind，不改 `SessionEvent` / `TimelinePage` / `LiveEvent` 契约，不动后端投影与存储。

## 测试与验收

- 遵循 TDD：先写失败测试，确认失败原因正确后完成最小实现。
- 完成回合场景（mock timeline 含 turn.start → user → 中间 assistant → 工具调用 → final assistant → turn.end(completed)）：
  - 组头为「已执行 · 1 条命令 · 用时X」（含 `tool.call` shell）或「本轮已完成，用时X」（无统计口径的工具事件，如仅 result）；
  - "复制消息"按钮全场仅一个（轮尾总结），组内中间助手消息与用户消息均无按钮；
  - 点击轮尾复制按钮，剪贴板收到整轮合并文本；
  - 过程组默认收起、点击组头展开（jsdom 兜底断言 `details.open` 布尔值）。
- 运行中场景（open turn）：组头「正在执行 · …」带扫光类；组默认展开；空正文中间消息不渲染；点击组头可折叠（`details.open` 翻转）。
- 异常终态逐条按钮用例保持通过（按钮数扣除用户消息）。
- Shell 命令行：完成态不渲染状态词，异常终态显示红色状态词；行点击后 `aria-expanded` 切换；运行态显示「正在执行」。
- 用户消息：`.user-bubble` 包裹正文与引用，全场无头像元素。
- 命令：`npm test` 全量（仓库根运行）、`npm run build`；Rust 四命令按提交约定照跑，确认纯前端改动无影响。
